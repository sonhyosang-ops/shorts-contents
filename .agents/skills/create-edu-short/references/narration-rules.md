# 내레이션 규칙

- 총 길이 목표는 60~75초다.
- 문장은 한 번 듣고 이해할 수 있도록 짧게 쓴다.
- 교과서 문장을 나열하지 않고 인과관계를 이야기로 연결한다.
- 도입부에서 정답을 모두 설명하지 않는다.
- 질문은 영상 전체가 답해야 할 핵심 질문 하나를 우선한다.
- 수치와 고유명사는 원자료에 있을 때만 사용한다.
- 핵심 문장마다 하나 이상의 `evidence_id`를 연결한다.
- 감탄, 공포, 과장 표현이 교육적 정확성을 해치지 않게 한다.
- 마지막 문장은 핵심 개념이나 의미를 한 문장으로 정리한다.

권장 뼈대:

```text
[강한 결과 또는 변화]
[핵심 질문]
[처음 상태]
[문제 또는 원인]
[보이지 않는 원리나 과정]
[해결 또는 변화]
[현재 결과]
[핵심 개념]
```
