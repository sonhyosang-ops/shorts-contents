# 샘플 영상 문법

## 이야기 구조

1. 0~3초: 결과, 변화, 위험 또는 예상 밖의 장면을 먼저 보여 준다.
2. 3~7초: “왜 이런 일이 일어났을까?”에 해당하는 핵심 질문을 던진다.
3. 중반 전반: 과거 상황 또는 최초 상태와 원인을 보여 준다.
4. 중반 후반: 문제 발생 과정이나 보이지 않는 원리를 단면·투시·경로
   애니메이션으로 시각화한다.
5. 후반: 해결 과정 또는 변화가 일어나는 과정을 단계적으로 보여 준다.
6. 결말: 현재 모습과 핵심 개념·명칭을 명확히 정리한다.

주제에 따라 ‘과거-현재’가 맞지 않으면 다음 대응 구조를 사용한다.

- 과학: 현상 → 질문 → 조건 → 원리 → 결과 → 개념
- 기술: 결과 → 문제 → 구조 → 작동 과정 → 활용 → 명칭
- 사회: 변화 → 질문 → 배경 → 원인 → 영향 → 의미
- 절차: 완성 결과 → 실패·문제 → 단계 → 핵심 요령 → 완성

## 시각 문법

- 화면: 세로 9:16, 1080×1920 기준
- 스타일: cinematic 3D educational animation, detailed miniature,
  realistic but simplified materials
- 시점: 항공, 아이소메트릭, 눈높이, 단면을 내용에 맞게 교차 사용
- 움직임: 부드러운 전진·하강·회전, 필요한 경우 제한된 빠른 줌
- 그래픽: 경로·힘·흐름·균열·범위는 화살표나 발광선으로 표시
- 색상: 문제는 낮은 채도, 해결·이해는 파랑·초록 또는 밝은 색 증가
- 편집: 보통 2~4초 단위, 내레이션 의미 단위마다 장면 전환

실제 자막, 수치, 명칭은 후반 편집에서 추가한다. 생성형 영상 안에는
문자나 플랫폼 UI를 만들지 않는다.
