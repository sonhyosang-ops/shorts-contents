# 검수 기준

## 교육 검수

- 원자료 충실성 90점 이상
- 학습자 적합성 85점 이상
- 원자료 밖 사실 추가 0건
- 근거 없는 수치·날짜 0건
- 치명적 오개념 0건

## 영상 검수

- 구현 가능성 80점 이상
- 첫 3초 훅 존재
- 전체 길이 60~75초
- 한 장면의 핵심 행동은 원칙적으로 1개
- 내레이션과 화면의 의미 불일치 0건
- 프롬프트 안의 문자 생성 지시 0건
- 장면 사이 인물·공간·시대·색상 일관성 유지

## 단계 복귀 규칙

| 문제 | target_stage |
|---|---|
| 원자료 오독, 근거 오류, 인과 왜곡 | analysis |
| 훅, 문장, 길이, 학년 수준 | narration |
| 장면 과밀, 카메라, 연결, 시각 일관성 | storyboard |

치명적 문제가 있거나 임계 점수에 못 미치면 `pass=false`다.
수정 지시는 오류 위치, 근거, 바꿀 내용이 드러나야 한다.
