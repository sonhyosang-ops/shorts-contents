# 형식별 원자료 처리

## 공통

- 원본 파일명·URL·위치 정보를 유지한다.
- 읽을 수 있는 원문과 직접 관찰한 시각 설명을 구분한다.
- OCR·자동 전사 결과는 오독 가능성을 확인 항목으로 남긴다.

## 문서와 슬라이드

| 형식 | 처리 | 위치 표기 |
|---|---|---|
| PPTX | 텍스트·발표자 노트·도형 안 텍스트를 추출하고 슬라이드 렌더링으로 도표·이미지를 확인한다. | 슬라이드 번호 |
| PDF | 텍스트·표를 추출하고 페이지 렌더링으로 누락·레이아웃을 확인한다. | 페이지 번호 |
| DOCX | 본문·표·각주·댓글을 추출한다. | 제목 또는 문단 순번 |
| HWP/HWPX | 본문·표·각주를 추출한다. | 쪽수 또는 문단 순번 |

PPTX, PDF, DOCX, HWP/HWPX는 해당 전용 문서 처리 스킬을 먼저 사용한다. 슬라이드 이미지 속 글자나 그래프 축 값이 자동 추출되지 않으면 `자료 확인 필요`로 남긴다.

## 표와 데이터

XLSX·XLS·CSV·TSV는 시트명, 셀 범위, 열 머리글을 함께 기록한다. 계산식의 결과와 수식 자체를 구분하고, 단위·기간·결측값이 불명확하면 추정하지 않는다.

## 이미지·음성·영상

- 이미지: OCR 텍스트와 직접 보이는 요소만 분리해 기록한다. 사진의 맥락·인물·장소를 추측하지 않는다.
- 음성·영상: 전사문에 화자·시간 범위를 붙인다. 알아듣기 어려운 구간은 `[불명확]`과 시간 범위로 표시한다.
- 영상 슬라이드나 화면 녹화: 화면 글자는 OCR 결과와 시각 범위를 함께 남긴다.

## 웹 자료와 혼합 자료

URL은 접속 시점과 URL을 기록하고, 실제로 읽은 본문만 인용한다. 여러 파일은 S001부터 순서대로 ID를 부여한다. 같은 주장을 반복하는 자료라도 출처 ID를 합치지 않는다.
